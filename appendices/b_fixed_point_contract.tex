\section{Threshold definitions}

For thresholds $\theta_1<\theta_2<\theta_3$, the four-level bin function is
\begin{equation}
b(x;\theta_1,\theta_2,\theta_3)=
\begin{cases}
0,&x<\theta_1,\\
1,&\theta_1\leq x<\theta_2,\\
2,&\theta_2\leq x<\theta_3,\\
3,&x\geq\theta_3.
\end{cases}
\label{eq:bin-contract}
\end{equation}
Equality enters the higher bin. Testing below, at, and above every threshold gives
36 directed threshold-edge cases for four features and three thresholds.

\section{Profile payload}

Each $\alpha$ coefficient is encoded as a three-bit unsigned half-unit numerator,
and each Tchebycheff ratio uses two unsigned bits. The 18-bit word is
\[
\alpha_1[2{:}0]\,\alpha_2[2{:}0]\,\alpha_3[2{:}0]\,\alpha_4[2{:}0]\,
\lambda_1[1{:}0]\,\lambda_2[1{:}0]\,\lambda_3[1{:}0].
\]
The four hexadecimal payloads are \texttt{13329}, \texttt{1B516},
\texttt{14399}, and \texttt{0A2A5}.

\textbf{Condition} & \textbf{Required behavior}\\
\midrule

The raw UART record carries the request identifier and the returned status,
configuration/profile identity, state, selected candidate, score, and cycle-related
fields required by the registered nine-field comparison. The UART layer transports
the record but is not included in kernel-cycle measurement.

\section{Latency boundary}

Cycle count begins at synchronous request acceptance and ends at the synchronous
\texttt{done} edge. Host parsing, UART serialization, operating-system scheduling,
JTAG, programming, KMS access, candidate generation, and route installation are
outside this boundary.
