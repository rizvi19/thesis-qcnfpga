\section{Tool versions}

The FPGA builds used Xilinx ISE 14.7. The final thesis was built with XeTeX
3.141592653-2.6-0.999995 and BibTeX 0.99d from MiKTeX 24.1. The retained OpenROAD
reports identify OpenROAD v2.0-19993-ga613c7e53. Remaining Python, Icarus Verilog,
Yosys, ngspice, and environment details are recorded by the version-controlled build
scripts and logs associated with each artifact family.

\section{Build and replay sequence}

\begin{enumerate}
  \item check out the branch and commit associated with the selected evidence set;
  \item verify registered source, ROM, and replay hashes;
  \item run the software reference and controller regression tests;
  \item compile and run unit and integrated RTL simulations;
  \item build one selected hardware configuration with Xilinx ISE 14.7;
  \item inspect synthesis, map, placement-and-route, and timing reports;
  \item program the volatile FPGA bitstream;
  \item run the common UART replay and retain the raw response;
  \item parse the response and compare all expected fields; and
  \item generate cross-configuration tables only after every configuration passes
  exactness.
\end{enumerate}

The CSV files under \path{data/} in the thesis package are direct copies or compact
extracts of the registered repository summaries. LaTeX figures use those reported
values or architectural diagrams drawn in the source.
